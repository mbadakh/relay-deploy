You own the deployment

Run Relay from your terminal, in your own AWS account or on your own computer.

  • Your infrastructure and AWS bill.
  • Your passwords and encryption keys.
  • No platform access to your account.
  • The same official Android app.

Pricing expectations

Local Docker uses your computer’s resources. Relay does not create an AWS account or charge a hosting fee.

AWS estimates include fixed services and modeled usage. They are not spending caps. Taxes, traffic and optional services can increase the bill.

Review before applying

The terminal creates an exact Terraform plan and an offline HTML cost report. Nothing in that plan is deployed until you approve its fingerprint.

Requirements: Git and Docker with Compose. AWS mode also needs your own authenticated AWS identity; the included tools container supplies AWS CLI and Terraform.

Start your own server

Choose where Relay should run. The commands execute on your computer.

Start the complete app suite

git clone https://github.com/mbadakh/relay-deploy.git
cd relay-deploy
docker compose up -d

Open http://localhost:8080 once startup completes. Retrieve your generated administrator password:

docker compose run --rm init cat /run/relay/admin.txt

The suite includes Relay, Keycloak, PostgreSQL, object storage, a web proxy and TURN. Data stays in Docker volumes.

Localhost is for use on this computer. To connect phones or remote users, configure a public HTTPS origin and reachable TURN ports before the first start. See the repository’s operations guide.

Configure your AWS server

Home lab reduces cost and has no high availability. Production separates application, database and TURN infrastructure.

Supply your domain and zone for managed DNS/TLS. Otherwise you receive a public IP or load balancer hostname. A trusted HTTPS reverse proxy is required before connecting the official mobile app.

Run from your terminal

git clone https://github.com/mbadakh/relay-deploy.git
cd relay-deploy

Use an existing AWS profile, or configure and sign in with the bundled CLI:

./relay aws configure sso
./relay aws sso login --profile YOUR_PROFILE

The command below skips configuration questions but still requires approval of the exact deployment plan.

You can also run ./relay with no flags for the interactive setup.
